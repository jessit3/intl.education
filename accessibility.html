Accessibility

We want everyone to be able to use this site, whatever device, ability or way of learning.

What we've done

  • Text and buttons meet WCAG 2.2 AA color contrast.
  • Every page works with a keyboard alone, with a visible focus outline.
  • Large, left-aligned text with comfortable line lengths, following Universal Design for Learning.
  • Animations are gentle and switch off if your device is set to reduce motion.
  • Images have text descriptions; decorative graphics are hidden from screen readers.

Tell us if something gets in your way

If any part of this site is hard to use, email hello@intl.education and we'll fix it or get you the information another way.
